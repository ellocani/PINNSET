# 검증 결과와 해석

대회 제출 ZIP의 `results/strict/` 집계표를 사용했습니다. 평가에는 검증 분할별로 산출한 예측을 사용했습니다.

## 모델 비교

시간순 평가는 시험 구간보다 앞선 자료를 사용합니다. 사건 블록 제외 평가는 시험 사건이 속한 블록 전체를 학습에서 빼고 나머지 블록을 사용합니다. 두 평가 모두 분할마다 정상 기준과 확률 보정층을 다시 계산합니다. 아래는 판정 가능한 부품을 같은 비율로 검사했을 때 찾은 불량 수입니다. 구간별 검사 대상 수를 정수로 정하므로 실제 검사율은 표의 명목 비율과 조금 다를 수 있습니다.

| 제품 | 구간별 검사 예산 | 시간순 | 사건 블록 제외 |
| --- | ---: | ---: | ---: |
| CN7 | 5% | 10/11 | 17/28 |
| RG3 | 50% | 22/27 | 26/31 |

CN7 사건 블록 제외 평가에서 로지스틱 회귀는 6/28, 히스토그램 그래디언트 부스팅(HistGB)은 0/28, Isolation Forest는 17/28을 검출했습니다. FLR을 뺀 PINNSET도 17/28을 검출해 이 예산에서 검출 수는 같았습니다. PINNSET의 Brier 점수는 0.00473으로, 학습 구간의 불량률을 사용하는 상수 기준 0.00733 대비 약 35% 낮았습니다. [모델 비교 집계 CSV](results/model_comparison.csv)

## 운영 규칙

운영 규칙은 각 제품의 판정 기준과 보류 시 대체검사를 적용합니다. 검사율의 분모는 아래 각 평가 범위의 부품 수입니다.

| 시간순 평가 범위 | 검사 대상 | 검사율 | 선정된 불량 |
| --- | ---: | ---: | ---: |
| CN7 전체 | 540 / 3,974 | 13.6% | 27/28 |
| CN7 처음 기준을 만들 수 없는 구간 제외 | 165 / 3,599 | 4.6% | 10/11 |
| RG3 전체 | 745 / 1,256 | 59.3% | 27/32 |

CN7 전체에서 찾은 불량 27개 중 17개는 첫 구간의 전수 대체검사로 포함됐습니다. RG3 전체는 부품의 59.3%를 검사 대상으로 선정해야 했으므로 검사량을 줄일 여지가 제한적이었습니다. [운영 규칙 집계 CSV](results/operating_comparison.csv)

## 해석 범위

- CN7 불량 28개 중 27개가 두 사건에 집중돼 있어 새 기간이나 새 레시피에서 같은 성능을 기대하려면 독립된 불량 사건으로 검증해야 합니다.
- 동일 샷의 LH·RH 부품은 공정값을 공유하므로 캐비티 위치별 편차와 개별 부품 불량을 구분하려면 캐비티별 측정이 더 필요합니다.
- PINN으로 추정한 온도장과 야코비안에 기반한 측정 제안은 원인 가설을 검토하는 데 사용했습니다. 제안의 효과는 후속 계측과 현장 시험으로 확인해야 합니다.
