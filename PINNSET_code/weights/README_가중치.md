# PINN 학습 가중치

PyTorch(2.11, float64)로 학습한 가중치다. 학습 코드는 `../pinn_torch/pinn_torch_train.py`, 학습·검증 기록은 `학습기록/`.
제출 파이프라인(run_all.py)은 학습된 가중치로 값만 계산하므로(`pinn_map.py`) PyTorch 없이 실행된다.

| 파일 | 실험 | 용도 |
|---|---|---|
| pinn_exp2_map.npz | 실험 2: 온도 의존 물성(ASA), 입력 = 위치·시간·유리전이 위치 θg | **성형 윈도우 지도** (금형온도 × 충진시간 × 용융온도) |
| pinn_exp1_const.npz | 실험 1: 물성 일정 | 검증용 (푸리에 급수 정답과 비교) |
| pinn_exp3_bi.npz, pinn_exp3b_bi.npz | 실험 3·3b: 역문제(접촉 열저항 Bi 역산) | 가중치 + 역산한 log(Bi). 보고서 그림 5-1 |
| pinn_exp4_resin.npz | 실험 4: 수지 일반화, 입력 = 위치·시간·θg·열확산율 비 r(1~2) | 열확산율 비가 다른 수지의 FLR (`flr(..., ratio=r)`). 검증 45조건 FDM 대비 중앙 0.00047·최대 0.00369 (학습기록/exp4/) |
| pinn_map.py | 불러오기·FLR·지도 계산 | `python pinn_map.py`로 재현 확인 |
| pinn_checks.json | 기준점·푸리에 급수 대조·입력 범위 검사 결과 | pinnset_strict.py가 물리 검산 기록에 포함 |
| 학습기록/ | verify_report(기준점·푸리에 급수·FDM·역산 Bi), train_log(손실 기록), train.log | 학습 환경 출력 그대로 |

- 신경망: 입력 → tanh 40 × 4층 → 출력 1 (실험 3: 32 × 3층, 실험 3b: 48 × 4층). 키: W0~W3, b0~b3, Wo, bo
- 입력 변환(무차원화·로그 시간·θg 정규화)은 pinn_map.py 맨 위 설명과 `PINN.theta()`에 그대로 있음. **이 변환 없이 가중치만 쓰면 틀린 값이 나온다.**
- 학습 범위: 시간 0.12~38.8초, θg 0.10~0.40 (용융 275.5℃면 금형온도 약 20~86℃). 범위 밖은 오류를 낸다.
- 금형온도·용융온도는 θg 하나로 합쳐져 들어간다(무차원화 결과). 그래서 용융온도가 달라도 θg 범위 안이면 같은 가중치로 계산 가능.

## 검증 결과 (학습기록/verify_report_exp1_2.md, 모두 통과)
| 검증 | 결과 |
|---|---|
| 기준점: 라벨 운전점(금형 22.8℃, 용융 275.5℃, 충진 4.45초) | 실험 2 → 0.1763, 실험 1 → 0.1722 |
| 기준점: 금형 50℃·4.45초 / 금형 80℃·8초 (실험 2) | 0.1322 / 0.1012 |
| 실험 1 vs 푸리에 급수 정답 (상대오차) | 4.45초 0.24%, 8초 0.97%, 11.2초 3.0% |
| 실험 2 vs FDM 수치해 (금형 20~80℃ × 충진 1.5·4.45·8초, 15조건) | 중앙 0.0009, 최대 0.0021 (허용 중앙 0.003) |
| 실험 3·3b 역산 Bi (정답 20) | 센서 없음 3.4~4.4, 센서·기본 12.5~15.9, 센서·보강 19.50~19.57 |

다른 수지·두께: PINN은 무차원 변수로 학습했으므로 `PINN.flr(T_mold, t_fill, T_melt, Tg=, Tnf=, half_mm=, a_melt=)`처럼 새 부품의 반두께·용융 열확산율·유리전이·무유동 온도만 바꿔 넣으면 같은 가중치로 계산된다(유리/용융 열확산율 비가 1.44로 같다는 가정). 비가 다른 수지는 실험 4 가중치(pinn_exp4_resin.npz, `ratio=` 인수)를 쓴다. 검산: pinnset_newrecipe.py ⑤.

지도 구현 참고: 샷별 (금형온도, 충진시간, 용융온도)를 넣으면 샷별 PINN FLR이 나온다. 위험점수 모델의 FLR은 반무한 해석해(erf)로 계산하는데, 충진 시점(약 4.4초)에선 PINN(온도 의존 물성)과의 차이가 약 2%(0.1726 vs 0.1763)라 결론은 같다.
