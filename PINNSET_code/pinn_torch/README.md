# PINN 학습 (pinn_torch)

PINN 실험 1·2·3·3b를 PyTorch로 학습하는 코드다. 제출 코드 `../weights/`의 가중치는 이 스크립트로 만들었다(학습·검증 기록: `../weights/학습기록/`).
제출 파이프라인(run_all.py)은 학습된 가중치로 값만 계산하므로 PyTorch 없이 돌아간다. 이 폴더는 "가중치를 처음부터 다시 만드는 경로"다.

## 실행
```bash
pip install -r requirements_torch.txt
python pinn_torch_train.py --exp 1 2 3 3b 4 --out weights_torch --data <labeled_data.csv 폴더> --figures   # 전체(실험 4 포함) + 그림. --exp all은 실험 4 제외
python pinn_torch_train.py --exp 1 2 --out weights_torch                                           # 지도용 가중치만 (실험 1·2)
python pinn_torch_train.py --exp 1 2 --quick --out tmp                                               # 동작 확인 (반복 1/20, 수렴 검증 아님. 종료 코드 0)
python pinn_torch_train.py --verify-only --out ../weights                                           # PyTorch 없이 제출 가중치 검증
python pinn_torch_train.py --exp 4 --device cuda --out weights_exp4                                 # 실험 4: 수지 일반화 (GPU 권장)
```
CPU 기준 소요(학습 기록): 실험 1 약 8분, 실험 2 약 10분, 실험 3(6회) 약 14분, 실험 3b(2회) 약 25분. GPU 불필요.

## 학습 설정
| 항목 | 내용 |
|---|---|
| 신경망 | 실험 1·2: 입력 2/3 → tanh 40 × 4층 → 1, 실험 3: 32 × 3층, 실험 3b: 48 × 4층 |
| 초기 가중치 | 시드 고정 `default_rng(seed).normal(0, √(1/입력 수))`, 편향 0 (실험 1 seed 1, 실험 2 seed 2, 실험 3·3b seed 10+시드) |
| 표본점 | 시드 고정 난수, 500회마다 새로 뽑기 |
| 입력 특징 | 2x̂−1, 2·log(t̂/0.002)/log(0.65/0.002)−1, (실험 2) 2(θg−0.10)/0.30−1. 실험 3은 시간 끝 0.20 기준 로그 |
| 손실 | 실험 1·2: 잔차(×t̂)² + 10·벽 θ=0 + 중심 θ_x=0 + 10·초기 erf, 실험 2는 열확산율 a(θ)=[0.115+(0.080−0.115)·σ((θ−θg)/0.03)]/0.080. 실험 3: Robin 벽 θ − θ_x/Bi, 센서 가중 100(3b: 30, 잔차 ×3) |
| 미분 | `torch.autograd.grad`(create_graph)로 u_t, u_x, u_xx |
| 최적화 | Adam(β 0.9/0.999, ε 1e-8). 실험 1: 2e-3, 4000·6000에서 ×0.3 / 실험 2: 2e-3, 5000·7000 / 실험 3: 3e-3, 4500 / 3b: 3e-3, 6000·8500 |
| 반복 | 실험 1 8,001 / 실험 2 9,001 / 실험 3 6,001 × 6회 / 실험 3b 10,001 × 2회 |
| 실험 4 (수지 일반화) | 입력 4개 → tanh 48 × 4층 → 1, seed 4. 열확산율 a(θ) = r + (1 − r)·σ((θ − θg)/0.03), r = α_유리/α_용융 ∈ [1, 2]를 표본마다 뽑음. 표본 4,000점, Adam 2e-3, 11000·15000·18000에서 ×0.3, 20,001회(`--iters4`로 변경) |
| 정밀도 | float64 |

CPU 종류·스레드 수에 따라 부동소수점 합산 순서가 달라 가중치 숫자가 비트 단위로 같지는 않을 수 있다. 같은 온도장을 배웠는지는 verify_report로 판정한다.

## 파일
pinn_torch_train.py(학습·검증), common.py(상수·정답 함수), fdm.py(FDM 수치해), viz_common.py·fig1~3.py(그림, 학습된 가중치로 값만 계산), requirements_torch.txt.

**검증 종료 코드**: 검증할 실험의 가중치 파일이 없거나 검증 항목이 0개이면 실패, 수치 기준을 못 넘으면 실패이며 둘 다 종료 코드 1을 반환한다. `--quick`은 동작 확인이므로 수치 기준 미달은 안내만 하고 종료 코드 0이다. `--verify-only --out ../weights`는 제출 가중치 폴더에 verify_report 파일을 만든다.
